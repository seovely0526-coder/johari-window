# 나를 비추는 창 — 조하리의 창

친구의 피드백을 받아 자기인식을 탐색하는 학교 탐구용 웹앱입니다.

## GitHub Pages에 올릴 파일
- `index.html` : 웹사이트
- `firestore.rules` : Firebase Firestore 보안 규칙
- `SETUP.md` : Firebase 연결 및 배포 안내
- `README.md` : 프로젝트 설명

## 배포 순서
1. Firebase에서 프로젝트와 Firestore를 만듭니다.
2. `index.html`의 `firebaseConfig`를 자신의 Firebase Web App 설정으로 교체합니다.
3. GitHub에 새 Public 저장소를 만듭니다.
4. 이 폴더의 파일을 저장소 최상위에 업로드합니다.
5. Settings → Pages → Deploy from a branch → `main` / `/ (root)` → Save.
6. 생성된 `github.io` 주소로 접속합니다.

개인정보를 수집하지 않도록 별명 사용을 권장합니다. 학교 발표·탐구용이라면 외모나 민감한 정보에 대한 평가를 받지 않도록 안내하세요.
